Arena reference

Field guide

  1. Observe the opening. Scrub or play the first 48 ticks. Pale grazers feed on plants. Orange hunters feed on grazers. The rocky, ochre terrain marks the highlands. The chart tracks all three populations.
  2. Forecast the ending. Set a probability for each question, enter your callsign and lock the slip. Field Agent makes its own forecast using the opening observations.
  3. Reveal the world. The host settles the round after entries are in. Watch the full 192 ticks and compare your score with the bot and other entrants.

How scoring works

A correct outcome is 1 for yes and 0 for no. The arena squares the difference between each probability and its outcome. Your score is 100 times one minus the average of those errors. Higher wins.

Solo and group play

The GitHub Pages edition runs solo in your browser. A shared challenge link includes the seed so friends can play the same world. Each browser scores its own forecasts. Run npm start to host on your computer. For a group on the same Wi-Fi, run HOST=0.0.0.0 npm start from the repository. Open the host computer’s LAN address in your browser, then copy that room link for your group.

Verify a multiplayer round

Save the seed commitment before the reveal. After settlement, download the replay receipt and check it with the repository’s verification command.
